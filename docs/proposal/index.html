5 · Content workflow

Fourteen steps, two quality loops, and nothing goes live without a person

Research›Brief›Writing›Fact Checking›SEO Review›Editorial Review›Human Approval›Published›Monitoring
  1. Finds the opportunity: keyword, volume, difficulty, intent.
    Keyword Research
  2. Studies the top 10 ranking pages and finds the gap.
    Competitor
  3. Accepts or drops the opportunity against the monthly plan.
    Head of SEO
  4. Writes the brief and names the target persona.
    Strategist + Brief
  5. Calls the right StarsTell bot. Every request and response is stored.
    Domain agent
  6. Collects external references with URLs and access dates.
    Fact Checking
  7. Writes the first draft only from the brief, bot answers and sources.
    Senior Writer
  8. Splits the draft into claims and gives each one a verdict.
    Fact Checking
  9. Meta, headings, internal links, schema, alt text.
    SEO Optimization
  10. Readability, repetition, brand voice, originality check.
    Senior Editor
  11. Human approval. Approve, reject, request revisions or edit. Festival, panchang, muhurat and remedy articles also need SME sign-off.
    People
  12. Publishes, adds metadata and schema, pings sitemap and IndexNow.
    CMS Publishing
  13. Tracks impressions, clicks, CTR, position, conversions.
    Analyst
  14. Flags decaying or outdated posts and opens refresh tasks.
    Refresh

Fact-check loop

Any claim marked unsupported or contradicted sends the draft back to the writer with the claim list. After 2 failed rounds the task goes to the Head of SEO and a person.

Editorial loop

The editor scores against a rubric. Below the bar, the draft returns to the writer, or to the brief if the angle is wrong. Maximum 3 rounds, then escalate.

Retries

API calls retry on timeouts and 5xx with backoff (3 tries). Errors that waiting cannot fix, like a bad key, fail at once with the reason on the task.

Audit log

Paperclip records every task change, run, cost and approval. The Content Service records every tool call, bot response and version.

Brand rules every draft is checked against: name the astrological mechanism, tie outcomes to the reader's own effort, never guarantee a result, never use fear to sell, never write "predict", "destiny" or "fate". No specific tithi, muhurat or festival date goes live without SME sign-off.
6 · API integration design

One adapter per bot, and nothing inside it is written until your documentation arrives

Adapter contract Proposed

  • Every bot is wrapped behind the same small interface in the Content Service.
  • Endpoints, parameters and response fields are copied from your docs, never guessed.
  • Each response is validated against a schema; a mismatch fails loudly.

What gets logged

  • Request, response, latency, status and cost per call.
  • Linked to the article and the claim that used it.
  • The writer quotes logged answers, so every interpretation is traceable.

Limits and failures

  • Rate limits from your docs become a queue, not errors.
  • Responses are cached per question to cut repeat calls.
  • If a bot is down, the task pauses with a clear reason.

Other integrations

  • CMS: draft and publish calls, behind the approval check.
  • Search Console and GA4: through OpenSEO's Google connection.
  • IndexNow: one call after each publish.

9 · Security

Keys stay on the server, publishing needs a person, and every action is logged

Secrets

  • Bot, CMS, DataForSEO and Anthropic keys live in Paperclip secrets or server environment variables.
  • Never in the browser, never in a prompt, never in chat.
  • Google access through an OAuth or service account you add to Search Console.

Permissions

  • Each agent gets only its own tools (see section 4).
  • cms_publish rejects any call without a recorded human approval id.
  • Paperclip connection actions set to "Ask first" for anything that changes the live site.

Network and access

  • Paperclip in authenticated mode on a private network or behind SSO.
  • OpenSEO with password accounts or Cloudflare Access.
  • Postgres not exposed to the internet; nightly backups.

Budgets and misuse

  • Monthly budget per agent and company, with warnings and hard stops.
  • Competitor pages and web results are treated as untrusted text, never as instructions.
  • No customer data from your bots enters articles or logs.
